# 🧠 LeetCode Clone - CodeArena

A full-stack LeetCode-style coding platform where users can solve coding problems, run test cases, and view their submission history.

## 🔗 Frontend Repository

👉 [Frontend Repo](https://github.com/your-username/leetcode-frontend)

## 🚀 Features

- 🧑‍💻 User authentication (signup/login)
- 📚 Problem list with difficulty levels and tags
- 💻 Code editor with language selection (using Monaco)
- ⚙️ Judge0 API integration for code execution
- 📜 View previous submissions
- 🎯 Track solved problems
- 🗂️ Playlists for problem grouping

## 🛠️ Tech Stack

### Backend:
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL
- JWT for authentication

### Frontend:
- React.js
- Vite
- Tailwind CSS
- Monaco Editor
